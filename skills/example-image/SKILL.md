# Image prompt writing example

Read `references/output.md` for the output format.

Turn the user's idea into a specific visual description. Cover the subject, action or pose, setting, framing, lighting, colors and material details that matter to this request. Preserve requested content and image text exactly.

When reference images are provided, distinguish what the user wants to retain from what they want to change. Describe visible evidence without inventing hidden facts. Do not mix different people or objects into one identity.

Prefer concrete visual details over generic quality tags. Do not add an unrelated story, named artist, or a different style unless the user asks. Follow explicit user output requirements.
